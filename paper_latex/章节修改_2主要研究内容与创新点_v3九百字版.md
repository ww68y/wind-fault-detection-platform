# 2. 主要研究内容与创新点

本节围绕风机叶片缺陷检测任务，概括本文的主要研究内容、关键难点和创新点。整体思路是以 MSF-YOLO 提升小尺度缺陷检测能力，并通过多模态推理模块将检测结果转化为可用于运维判断的分析结论。

## 2.1 研究内容

本文以风机叶片表面裂纹、孔洞、剥落和腐蚀四类缺陷为检测对象，整理训练集、验证集和测试集，并统一标注格式，为模型训练和测试提供数据基础。在算法层面，本文基于 YOLO 构建 MSF-YOLO 检测模型，引入 P2 高分辨率检测头、Shape-Aware Loss 和 Blade-Slice 切片融合推理，以增强模型对远距离小裂纹、小孔洞和早期腐蚀的识别能力。在平台层面，系统支持图片、批量图片和视频文件检测，并进一步结合原图、结果图、检测报告、置信度和风险规则，生成故障解释、风险等级、复检建议和维修工单。

## 2.2 研究难点

风机叶片缺陷检测的难点主要来自目标尺度、图像分辨率和结果解释三个方面。其中，小尺度缺陷特征退化与高分辨率推理细节损失是本文算法设计重点解决的两个问题。前者表现为远距离裂纹、小孔洞等缺陷在图像缩放后仅占少量像素，导致纹理和边缘信息被削弱；后者表现为高分辨率巡检图像在整图推理时局部细节被压缩，使早期腐蚀和细长裂纹容易漏检。

表 1-1 风机叶片缺陷检测关键难点与对应设计

| 序号 | 任务难点 | 对应设计 |
| --- | --- | --- |
| 1 | 小尺度缺陷易退化 | P2 高分辨率检测头 |
| 2 | 缺陷形态差异大 | Shape-Aware Loss |
| 3 | 困难类别学习不足 | 困难样本重加权 |
| 4 | 高分辨率推理细节损失 | Blade-Slice 切片融合 |
| 5 | 检测结果难以直接决策 | 多模态故障推理与运维建议 |

## 2.3 研究创新点

本文的创新点主要体现在算法改进和多模态决策闭环两个方面。第一，提出面向风机叶片小尺度缺陷的 MSF-YOLO 检测思路，通过 P2 高分辨率检测头保留浅层细节特征，提高模型对小裂纹、小孔洞和局部腐蚀的响应能力。第二，设计 Blade-Slice 切片融合推理流程，将高分辨率图像划分为重叠局部区域进行检测，再把结果映射回原图并融合，以减少整图缩放造成的细节损失。第三，构建检测结果驱动的多模态故障推理机制，将原图、检测结果图、检测报告和风险规则共同作为依据，输出风险等级、可能原因、复检要求和维修建议，形成“缺陷识别—风险解释—运维处置”的闭环。
