风机叶片缺陷检测工程 v0.1_baseline 版本说明

封版时间：2026-06-04
版本名称：v0.1_baseline
版本定位：当前稳定基线版本


一、版本目标

本版本用于固定当前已经可以稳定运行的风机叶片缺陷检测工程，作为后续 v0.2、v0.3 模型和系统功能升级的对照基线。

该版本已经具备：

1. YOLOv8 风机叶片缺陷检测模型；
2. 单张图片检测；
3. 批量图片检测；
4. 本地网页检测界面；
5. JSON 报告；
6. Markdown 报告；
7. 网页报告；
8. 历史检测记录；
9. 漏检样本分析结果；
10. 当前训练评估结果。


二、当前检测类别

当前模型检测 4 类风机叶片表面缺陷：

1. crack：裂纹
2. hole：孔洞
3. spalling：剥落
4. corrosion：腐蚀

说明：
blade 当前作为正常叶片图片，不作为缺陷检测类别。

九、封版意义

保留该版本的目的：

1. 后续代码改动出现问题时可以回看当前稳定版本；
2. 后续 v0.2 模型可以和 v0.1_baseline 做指标对比；
3. 项目展示或阶段验收时可以直接引用当前版本结果；
4. 便于整理项目说明书、PPT 和演示材料。


十、后续版本建议

v0.2 不建议立即重训。

建议先补充：

1. 真实巡检图片；
2. 低对比度裂纹；
3. 小孔洞；
4. 腐蚀边界模糊图片；
5. 正常叶片图片；
6. hard_cases 中的漏检和误检样本。

补充并修正数据后，再训练：

runs\detect\wind_fault_v0.2_realdata
