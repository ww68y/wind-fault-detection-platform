一、当前项目目标

本项目目前已经搭建成一个基于 YOLO 的风机叶片缺陷检测原型系统。

系统可以对风机叶片图片进行缺陷识别，当前支持检测 4 类缺陷：

1. crack：裂纹
2. hole：孔洞
3. spalling：剥落
4. corrosion：腐蚀

说明：
blade 类型目前作为正常叶片图使用，不作为缺陷类别进行检测。


二、已经完成的主要功能

1. 工程结构搭建

已经建立了一个较完整的工程目录，包括：

- src：核心代码
- scripts：训练、预测、分析脚本
- datasets：数据集目录
- runs：训练结果、检测结果、报告结果
- hard_cases：困难样本、漏检样本目录
- tests：基础测试


2. 数据集整理与转换

已经将原始数据整理为 YOLO 可以训练使用的数据格式。

当前数据集目录：

datasets\wind_blade_defect

其中包括：

- images\train：训练图片
- images\val：验证图片
- images\test：测试图片
- labels\train：训练标签
- labels\val：验证标签
- labels\test：测试标签
- data.yaml：YOLO 数据集配置文件


3. YOLO 模型训练

已经完成了基于 YOLOv8 的模型训练，并使用 GPU 进行了训练。

当前主要模型文件：

runs\detect\runs\wind_fault\gpu_640_b4_80e\weights\best.pt

这是目前接口和网页检测正在使用的模型。

当前模型大致效果：

- precision 约 0.947
- recall 约 0.934
- mAP50 约 0.943
- mAP50-95 约 0.829

说明：
这些指标来自当前训练结果，可以说明模型已经具备较好的初步检测能力，但仍需要继续用更多真实巡检图片进行验证和优化。


4. 单张图片检测

已经完成单张图片检测功能。

接口地址：

POST http://127.0.0.1:8000/detect

功能：

- 上传一张图片
- 调用 best.pt 模型进行检测
- 返回缺陷数量、缺陷类别、置信度、边框坐标
- 保存检测结果图
- 生成 JSON 和 Markdown 报告
- 生成可直接打开的网页报告
