## 0. 写作定位

本文提出一种面向风机叶片缺陷检测任务的多尺度形态感知检测方法 MSF-YOLO。该方法围绕风机叶片巡检图像中“小尺度、细长形态、类别不均衡、整图推理细节损失”四类关键问题展开，分别从检测结构、损失函数、训练采样分布和推理尺度补偿四个层面进行改进。

当前应采用的严谨表述为：

> 本文提出并实现 MSF-YOLO，用于提升模型对小尺度、细长形态和困难类别缺陷的建模能力。后续通过消融实验进一步验证各模块对检测性能的贡献。

当前不应采用的表述为：

> MSF-YOLO 显著提升检测精度，全面优于现有基线模型。

除非最终消融实验和对比实验均给出正向证据，否则上述强结论不能写入正文。

## 1. 研究背景与任务难点

风机叶片长期运行于复杂自然环境中，易出现裂纹、孔洞、腐蚀和表面剥落等缺陷。相较于通用目标检测任务，风机叶片缺陷检测具有更强的工程约束：缺陷区域通常占图像面积较小，形态差异显著，背景纹理复杂，并且漏检可能带来较高的运维风险。因此，该任务不仅要求模型具有较高的整体检测精度，还要求模型在困难类别、小目标和高分辨率巡检图像上保持稳定的召回能力。

本文将任务难点归纳为以下四点。

| 序号 | 任务难点 | 具体表现 | 对检测模型的影响 |
| --- | --- | --- | --- |
| D1 | 小尺度缺陷特征易退化 | 远距离裂纹、小腐蚀点和小孔洞在整图缩放后仅占少量像素 | 深层下采样后目标纹理和边缘信息不足，导致漏检 |
| D2 | 缺陷形态差异大 | 裂纹呈细长结构，腐蚀和剥落呈不规则区域 | 常规框回归损失对小面积和细长框约束不足 |
| D3 | 类别分布与难度不均衡 | corrosion、crack 等类别更易低置信度或漏检 | 训练过程被易学类别主导，困难类别学习不足 |
| D4 | 高分辨率图像推理存在尺度损失 | 整图输入时小缺陷被压缩，局部细节被削弱 | 普通全图推理难以兼顾全局语义与局部细节 |

围绕上述难点，MSF-YOLO 的设计目标不是简单堆叠模块，而是建立“结构增强、形态约束、样本重分布、推理补偿”的完整检测链路。

## 2. 方法总体框架

MSF-YOLO 的总体框架如图 1 所示。训练阶段，模型在 YOLO 检测框架基础上引入 P2 高分辨率检测分支，并通过 Shape-Aware Loss 和困难样本重加权机制强化小尺度、细长形态与困难类别样本的学习。推理阶段，Blade-Slice 采用重叠切片与全图检测结果融合，缓解高分辨率图像整图缩放造成的细节损失。

![图 1 MSF-YOLO 总体框架](figures/fig_1_msf_yolo_framework.svg)

整体优化目标可表示为：

```math
\theta^*=\arg\min_\theta \mathbb{E}_{i\sim p}
\left[\mathcal{L}_{det}(I_i,Y_i;\theta,q)\right]
```

其中，\(I_i\) 表示输入图像，\(Y_i\) 表示对应标注，\(\theta\) 为模型参数，\(p_i\) 为困难样本重加权后形成的采样概率，\(q_i\) 为 Shape-Aware Loss 中根据目标形态计算得到的框级权重。

### 2.1 模块组成

| 模块 | 作用阶段 | 技术作用 | 是否写入权重 | 对应难点 |
| --- | --- | --- | --- | --- |
| P2 高分辨率检测头 | 训练与推理 | 增加 stride=4 的浅层检测分支，增强小目标特征保留 | 是 | D1 |
| Shape-Aware Loss | 训练 | 对小面积和细长目标的框回归与 DFL 损失加权 | 是 | D2 |
| 困难样本重加权 | 训练 | 提高 crack、corrosion 和小目标样本的抽样概率 | 是 | D3 |
| 类别权重 BCE | 训练 | 根据类别频次调整分类损失贡献 | 是 | D3 |
| 小目标数据增强 | 训练 | 通过高分辨率、多尺度、mosaic 和 copy-paste 扩展训练分布 | 是 | D1、D3 |
| Blade-Slice 融合推理 | 推理与评估 | 局部切片检测后回映射并与全图结果 NMS 融合 | 否 | D4 |

## 3. P2 高分辨率小目标检测分支

常规 YOLO 检测头通常从 P3 层开始预测，其最小检测 stride 为 8。对于远距离小裂纹、小孔洞或小腐蚀区域，目标经过多次下采样后容易退化为极少数特征单元。MSF-YOLO 引入 P2 分支，将最小检测 stride 扩展至 4，以提高浅层纹理和边缘信息对检测头的可见性。

设输入图像宽高为 \(W\times H\)，第 \(l\) 个检测层 stride 为 \(s_l\)，其特征图尺寸可表示为：

```math
F_l\in\mathbb{R}^{C_l\times \lceil H/s_l\rceil\times \lceil W/s_l\rceil}
```

MSF-YOLO 采用的多尺度检测层为：

```math
s_{P2}=4,\quad s_{P3}=8,\quad s_{P4}=16,\quad s_{P5}=32
```

目标 \(b\) 在第 \(l\) 层特征图上覆盖的近似单元数为：

```math
n_{cell}(b,l)=\frac{\sqrt{w_bh_b}}{s_l}
```

由此可见，当 \(s_l\) 较小时，同一像素尺度目标在特征图上覆盖的网格数量更多。P2 分支的意义在于为小缺陷保留更充分的空间表达，降低小目标在深层特征中被过度压缩的风险。

| 检测层 | stride | 1024 输入下特征图尺寸 | 主要关注目标 |
| --- | ---: | ---: | --- |
| P2 | 4 | 256 × 256 | 小裂纹、小腐蚀、小孔洞 |
| P3 | 8 | 128 × 128 | 小目标和中等目标 |
| P4 | 16 | 64 × 64 | 中等目标 |
| P5 | 32 | 32 × 32 | 大目标和强语义目标 |

论文表述建议：

> 通过引入 P2 高分辨率检测分支，MSF-YOLO 将浅层纹理信息直接纳入检测头，使小尺度缺陷在特征图上获得更多响应单元，从结构层面缓解小目标特征退化问题。

## 4. Shape-Aware 形态感知损失

风机叶片缺陷并非规则目标。裂纹通常呈细长结构，腐蚀和孔洞可能面积较小且边界不规则。若仍采用统一权重的框回归损失，小面积和细长缺陷对总体损失的贡献容易被大面积或易定位样本稀释。为此，MSF-YOLO 设计 Shape-Aware Loss，根据目标面积占比和长宽比为正样本框分配形态权重。

Shape-Aware Loss 的计算流程如图 2 所示。

![图 2 Shape-Aware Loss 权重计算流程](figures/fig_2_shape_aware_loss.svg)

对第 \(i\) 个正样本框，定义面积占比 \(A_i\) 和长宽比 \(R_i\)：

```math
A_i=\frac{w_ih_i}{WH},\qquad
R_i=\max\left(\frac{w_i}{h_i},\frac{h_i}{w_i}\right)
```

小目标项和细长项分别定义为：

```math
S_i=clip\left(\frac{a_0-A_i}{a_0},0,1\right)
```

```math
E_i=clip\left(\frac{R_i-r_0}{r_0},0,1\right)
```

最终形态权重为：

```math
q_i=clip(1+\alpha S_i+\beta E_i,1,q_{max})
```

当前参数设置为：

| 参数 | 数值 | 含义 |
| --- | ---: | --- |
| \(a_0\) | 0.012 | 小目标面积阈值 |
| \(r_0\) | 3.0 | 细长目标长宽比阈值 |
| \(\alpha\) | 0.35 | 小面积目标增益 |
| \(\beta\) | 0.25 | 细长目标增益 |
| \(q_{max}\) | 1.7 | 最大形态权重 |

加权框回归损失和加权 DFL 损失分别为：

```math
\mathcal{L}_{box}^{shape}=
\frac{\sum_{i\in\Omega^+}(1-CIoU_i)t_iq_i}
{\sum_{i\in\Omega^+}t_i}
```

```math
\mathcal{L}_{dfl}^{shape}=
\frac{\sum_{i\in\Omega^+}DFL_i t_iq_i}
{\sum_{i\in\Omega^+}t_i}
```

其梯度贡献可写为：

```math
\nabla_\theta \mathcal{L}_{box}^{shape}
=\frac{1}{T}\sum_{i\in\Omega^+}t_iq_i
\nabla_\theta(1-CIoU_i)
```

当 \(q_i>1\) 时，说明该目标的小面积或细长属性更明显，其定位误差在反向传播中获得更大的梯度贡献。

| 目标形态 | 几何条件 | 优化含义 |
| --- | --- | --- |
| 小腐蚀、小孔洞 | \(A_i\) 较小 | 增强小面积缺陷定位约束 |
| 细长裂纹 | \(R_i\) 较大 | 增强细长框边界和尺度约束 |
| 极端小且细长目标 | \(A_i\) 小且 \(R_i\) 大 | 通过 \(q_{max}\) 截断避免梯度过大 |

论文表述建议：

> Shape-Aware Loss 并不引入像素级边界监督，而是在检测框级别将目标几何形态转化为损失权重，使小面积和细长缺陷在框回归阶段获得更高学习优先级。

## 5. 困难样本重加权训练机制

在风机叶片缺陷数据中，crack 与 corrosion 往往具有更高的漏检风险。MSF-YOLO 通过图像级困难样本重加权改变训练采样分布，使困难类别和小目标样本在训练过程中以更高概率出现。

图像级采样权重定义为：

```math
w_i=clip(1.0\cdot 3.0^{\mathbb{1}[corrosion]}
\cdot 2.0^{\mathbb{1}[crack]}
\cdot 1.5^{\mathbb{1}[small]},0.05,6.0)
```

其中小目标触发条件为：

```math
\mathbb{1}[small]=1
\quad\text{if}\quad
c\in\{crack,corrosion\},\ A_i\le 0.012
```

采样概率与期望出现次数为：

```math
p_i=\frac{w_i}{\sum_{j=1}^Nw_j},\qquad
\mathbb{E}[m_i]=N\cdot p_i
```

| 样本类型 | 触发条件 | 权重系数 |
| --- | --- | ---: |
| 普通样本 | 未触发困难条件 | 1.0 |
| 裂纹样本 | 包含 crack | 2.0 |
| 腐蚀样本 | 包含 corrosion | 3.0 |
| 小目标样本 | crack/corrosion 且面积占比不高于 0.012 | 1.5 |
| 上限截断 | 多条件叠加后超过上限 | 6.0 |

同时，分类损失中引入类别权重：

```math
\tilde{\alpha}_c=\left(\frac{1}{n_c}\right)^{0.35},
\qquad
\alpha_c=\frac{\tilde{\alpha}_c}
{\frac{1}{C}\sum_{k=1}^C\tilde{\alpha}_k}
```

```math
\mathcal{L}_{cls}^{cw}=
\frac{\sum_{j,c}\alpha_c BCE(\hat{s}_{j,c},s_{j,c})}
{\sum_{j\in\Omega^+}t_j}
```

困难样本重加权和类别权重分别作用于“样本被看到的概率”和“分类误差的损失比例”。二者不应混写为同一种机制。

## 6. Blade-Slice 重叠切片融合推理

Blade-Slice 是推理阶段的尺度补偿策略，不写入 `.pt` 权重。其核心思想是在全图检测基础上增加局部切片检测，将局部检测框回映射到原图坐标后，与全图检测结果进行 NMS 融合。

Blade-Slice 流程如图 3 所示。

![图 3 Blade-Slice 重叠切片融合推理流程](figures/fig_3_blade_slice_pipeline.svg)

设切片边长 \(L=640\)，重叠率 \(\rho=0.25\)，则滑动步长为：

```math
d=\lfloor L(1-\rho)\rfloor=480
```

切片起点集合为：

```math
S_x=\{0,d,2d,\ldots,W-L\},\qquad
S_y=\{0,d,2d,\ldots,H-L\}
```

切片图像为：

```math
C_{u,v}=I[u:u+L,v:v+L]
```

局部检测框回映射为：

```math
b^{global}=(x_1+u,y_1+v,x_2+u,y_2+v,c,p)
```

最终融合结果为：

```math
\mathcal{B}_{fused}=NMS(\mathcal{B}_{full}\cup\mathcal{B}_{slice},\tau)
```

论文表述建议：

> Blade-Slice 通过局部窗口检测缓解整图缩放造成的小缺陷信息损失。由于该模块仅作用于推理阶段，本文在实验设计中将其作为独立消融项置于最后，以区分训练链路改进与推理策略改进。

## 10. 结果出来后的结论写法规则

最终结论应由实验事实决定，建议采用以下规则。

| 实验现象 | 可写结论 | 禁止写法 |
| --- | --- | --- |
| P2 提升小目标 Recall 且 FP_bg 不升 | P2 对小尺度缺陷检测具有有效贡献 | P2 全面提升所有类别性能 |
| Shape Loss 提升 crack/corrosion mAP50-95 | 形态感知损失增强了小面积或细长缺陷定位能力 | Shape Loss 显著提高所有指标 |
| Hard Sampling 提升困难类别但 Precision 下降 | 重加权改善困难类别学习，但需权衡误检风险 | 重加权机制完全解决类别不均衡 |
| Blade-Slice 多召回但误检增加 | 切片推理对特定小目标场景有补偿作用，但需要置信度门控 | Blade-Slice 直接提升工程可靠性 |
| A4 全面优于 A0-A3 | 可写 MSF-YOLO 整体有效，并给出提升幅度 | 不给数据直接写显著提升 |

## 11. 可直接进入论文的创新点表述

> 针对风机叶片巡检图像中缺陷目标尺度小、形态差异大、背景干扰强和类别分布不均衡等问题，本文提出一种多尺度形态感知检测方法 MSF-YOLO。该方法在 YOLO 检测框架基础上引入 P2 高分辨率浅层检测分支，以增强小裂纹、小腐蚀和小孔洞的特征表达；进一步设计 Shape-Aware 形态感知损失函数，根据缺陷框面积占比和长宽比动态调整定位损失权重，提高模型对小面积和细长目标的学习强度；同时构建困难样本重加权训练与 Blade-Slice 重叠切片融合推理机制，从训练分布和推理尺度两个层面提升复杂场景下的缺陷检测稳定性。

这段可以作为“本文创新点”或“方法总述”的基础版本。消融结果出来后，只需要在末尾补充具体实验收益和边界。
