三、视频检测功能

新增文件：

src\wind_fault\video\video_detector.py
scripts\predict_video.py

功能：

- 支持 mp4、avi、mov、mkv、wmv 等视频文件
- 对视频逐帧执行 YOLO 检测
- 输出带检测框的视频
- 保存关键帧截图
- 生成 JSON 视频检测报告
- 生成 Markdown 视频检测报告
- 统计视频中的缺陷类别、缺陷数量、缺陷帧数、最高置信度和风险等级

输出目录：

runs\video_detect

示例命令：

python scripts\predict_video.py --model runs\detect\runs\wind_fault\gpu_640_b4_80e\weights\best.pt --source 视频文件路径.mp4 --conf 0.3 --project runs\video_detect --device 0

本轮测试命令：

python scripts\predict_video.py --model runs\detect\runs\wind_fault\gpu_640_b4_80e\weights\best.pt --source runs\video_detect\sample_input.avi --conf 0.3 --project runs\video_detect --name sample_check_v2 --device 0 --max-keyframes 5

测试结果：

- 视频检测成功
- 6 帧测试视频全部完成推理
- 检出 hole、crack、spalling
- 已生成带框视频
- 已生成关键帧
- 已生成 video_detection_report.json
- 已生成 video_detection_report.md

测试输出目录：

四、摄像头实时检测功能

新增文件：

scripts\camera_realtime.py

功能：

- 默认使用电脑摄像头 source=0
- 实时显示检测画面
- 显示当前状态、风险等级、FPS、缺陷数量
- 检测到高风险缺陷时自动截图
- 自动保存截图对应的 JSON 结果
- 支持按 q 退出
- 退出时生成 camera_session_summary.json

示例命令：

python scripts\camera_realtime.py --model runs\detect\runs\wind_fault\gpu_640_b4_80e\weights\best.pt --source 0 --conf 0.3 --device 0

说明：

本轮没有直接打开摄像头，以免打断当前电脑操作；已完成脚本语法和命令行参数验证。
