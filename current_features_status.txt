风机叶片缺陷检测工程 - 现阶段已完成功能说明
生成日期：2026-06-04

一、项目当前定位

本工程当前定位为“风机叶片缺陷检测与本地推理展示平台”。

系统目前已经具备基于 YOLO 的风机叶片缺陷识别能力，可以对图片、批量图片和视频进行本地检测，并在网页中展示检测结果、历史记录和关键帧结果。

当前工程不是最终完整商用系统，而是一个已经可以运行、可以演示、可以继续扩展的原型工程。后续可以继续加入多模态故障分析、风险评估、运维建议、模型融合和更完整的报告功能。


二、已完成的核心功能

1. YOLO 缺陷检测模型训练

已完成风机叶片缺陷检测模型训练，当前主要模型支持以下 4 类缺陷：

- crack：裂纹
- hole：孔洞
- spalling：剥落
- corrosion：腐蚀

当前主要模型文件位置：

runs\detect\runs\wind_fault\gpu_640_b4_80e\weights\best.pt

该模型已接入本地检测接口和网页端，可以直接用于图片检测和视频检测。


2. 单张图片检测

已实现单张图片上传检测功能。

用户可以在本地网页上传一张风机叶片图片，系统会调用 YOLO 模型进行推理，并返回：

- 检测到的缺陷类别
- 缺陷置信度
- 缺陷检测框
- 缺陷数量
- 原图
- 带检测框的结果图

本地网页地址：

http://127.0.0.1:8000/

接口形式：

POST /detect


3. 批量图片检测

已实现批量图片检测功能。

用户可以一次选择多张图片进行检测，系统会逐张推理，并统计本次批量任务中的图片数量、缺陷数量和检测结果。

批量检测结果会保存到运行目录中，便于后续复查。

接口形式：

POST /detect/batch


4. 视频检测

已实现视频上传检测功能。

用户可以上传视频文件，系统会逐帧抽样检测，并生成：

- 原视频预览
- 检测结果视频
- 视频关键帧
- 每个关键帧的缺陷数量
- 每个关键帧的检测截图

目前已经安装并接入 FFmpeg，可以生成浏览器可播放的 H.264 MP4 预览视频。

视频检测的主要作用：

- 用于模拟无人机巡检视频中的缺陷识别
- 用于查看模型在连续画面中的检测稳定性
- 用于发现误检、漏检、低置信度检测等问题
- 用于后续扩展视频报告和多模态分析


5. 本地 FastAPI 服务

已搭建 FastAPI 后端服务。

当前后端可以提供：

- 健康检查
- 图片检测
- 批量图片检测
- 视频检测
- 静态网页访问
- 检测结果文件访问
- 历史记录访问

健康检查地址：

http://127.0.0.1:8000/health

本地工作台地址：

http://127.0.0.1:8000/


6. 网页端检测工作台

已完成一个本地网页检测工作台。

网页端当前支持：

- 上传图片
- 上传多张图片
- 上传视频
- 设置置信度阈值
- 开始检测
- 展示原图
- 展示检测结果图
- 展示检测状态
- 展示图片数量或视频帧数
- 展示缺陷总数
- 展示文件名称
- 展示历史记录
- 展示视频关键帧
- 点击关键帧查看大图

网页目前主要用于本地演示和调试，后续还可以继续美化界面、增加报告入口和多模态分析区域。


7. 检测报告与结果保存

系统已经支持将每次检测任务的结果保存下来。

当前已支持的结果形式包括：

- 检测结果图片
- detection_report.json
- detection_report.md
- 网页端结果展示
- 历史任务记录

这些结果可以用于后续复查，也可以作为多模态分析模块的输入。


8. 漏检样本整理

已完成漏检样本整理功能。

前期根据检测结果整理出部分疑似漏检图片，并复制到：

hard_cases\missed_samples

该目录用于集中保存模型没有检出的困难样本，后续可以用于：

- 人工复查
- 重新标注
- 补充训练集
- 提升细小缺陷检测能力


9. DTU 1024 切片数据接入

已完成 DTU 数据集的初步接入工作。

已做内容：

- 从 DTU 原始大图中自动切出 1024 尺寸小图
- 根据 DTU 标注 JSON 转换为 YOLO 格式数据集
- 生成 DTU 专用训练数据目录
- 完成 DTU 训练流程测试
- 启动 DTU 1024 数据训练

DTU YOLO 数据集位置：

datasets\dtu_1024_yolo

DTU 切片原图位置：

datasets\raw\dtu\images

DTU 标注仓库位置：

datasets\raw\dtu_annotations

DTU 训练结果目录：

runs\detect\runs\wind_fault\dtu\dtu_1024_b1_80e_20260604_171248

当前 DTU 训练已经产出权重文件：

runs\detect\runs\wind_fault\dtu\dtu_1024_b1_80e_20260604_171248\weights\best.pt

说明：DTU 模型是另一套 5 类缺陷体系，和当前网页默认使用的 4 类模型不是同一个模型。后续需要根据实际效果决定是否合并训练、迁移训练或单独作为细小缺陷模型使用。


10. GPU 训练环境

已完成 NVIDIA 驱动更新和 GPU 训练环境检查。

当前环境已能识别并使用 NVIDIA GeForce GTX 1650 进行训练。

训练过程中已经验证：

- torch 可以识别 CUDA
- YOLO 可以使用 device 0 调用 GPU
- 1024 图像尺寸在 batch=1 时可以正常训练

说明：GTX 1650 显存较小，1024 尺寸训练不适合设置过大的 batch。当前推荐 batch=1 或较小 batch，优先保证训练稳定。


三、当前主要工程目录说明

1. 源码目录

src\wind_fault

主要存放后端接口、检测逻辑和网页静态文件。


2. 网页文件

src\wind_fault\api\static\index.html

本地检测工作台页面。


3. 数据集目录

datasets

当前包含：

- wind_blade_defect：原风机叶片缺陷数据集
- dtu_1024_yolo：DTU 1024 切片 YOLO 数据集
- raw：原始数据和标注转换数据


4. 训练结果目录

runs

保存模型训练、预测、视频检测和接口运行结果。


5. 脚本目录

scripts

当前包含训练、预测、数据准备、DTU 切片转换等脚本。


四、当前已经可以演示的流程

演示流程一：图片检测

1. 启动 FastAPI 服务
2. 打开 http://127.0.0.1:8000/
3. 上传一张风机叶片缺陷图片
4. 点击开始检测
5. 查看原图、检测结果图、缺陷数量、检测状态
6. 在历史记录中查看本次任务


演示流程二：批量图片检测

1. 在网页中选择多张图片
2. 点击开始检测
3. 系统逐张完成检测
4. 页面显示总图片数量和总缺陷数量
5. 后端保存检测结果


演示流程三：视频检测

1. 在网页中选择视频文件
2. 点击检测视频
3. 系统抽帧并逐帧检测
4. 页面显示原视频、检测结果视频和关键帧
5. 点击关键帧可以查看大图


五、当前还没有完全完成的功能

以下功能属于下一阶段开发内容，目前还未作为稳定功能完成：

DTU 数据集已经接入并开始训练，但是否和当前 4 类模型合并，还需要进一步评估。

后续需要重点观察：

六、当前项目价值总结

目前工程已经从“只有模型训练”推进到了“可以本地上传、检测、展示、保存、复查”的完整原型。

现阶段已经具备以下价值：

- 可以演示风机叶片缺陷检测流程
- 可以使用训练好的 YOLO 模型检测图片
- 可以批量检测图片
- 可以检测视频并查看关键帧
- 可以保存检测报告和历史记录
- 可以整理漏检样本继续优化模型
- 已经接入 DTU 1024 数据，为提升细小缺陷检测能力打下基础

下一阶段最适合推进的方向是：

在现有 YOLO 检测系统后面新增“多模态故障分析模块”。YOLO 负责发现缺陷，规则系统负责判断风险，多模态分析模块负责解释故障并生成运维建议，网页负责展示完整检测与分析结果。
